# Glossary

**ABI** — 跨二进制模块约定调用、名称、布局、异常和运行库交互的接口（Ch 3, 4, 9, 10）。

**BSS** — 描述未初始化/零初始化数据的节，运行时占空间而文件通常不存放等量零字节（Ch 3, 6）。

**BFD** — binutils 用于抽象多种二进制文件格式的库（Ch 4）。

**COFF** — ELF 与 PE 发展史相关的通用目标文件格式家族（Ch 3, 5）。

**CRT** — C/C++ 运行库及程序启动、初始化、I/O、堆和退出支持（Ch 11, 13）。

**DLL** — Windows 下使用 PE 格式的动态链接模块（Ch 9）。

**ELF** — Linux 常见的可执行、目标与共享对象格式（Ch 3, 6, 7）。

**GOT** — 运行时保存外部或全局地址的全局偏移表（Ch 7）。

**IAT** — Windows 调用方保存导入函数最终地址的表（Ch 9）。

**Image Base** — PE 映像偏好的装载基址（Ch 5, 9）。

**Lazy Binding** — 在第一次函数调用时才解析外部符号（Ch 7）。

**PIC** — 不依赖固定装载地址的位置无关代码（Ch 7）。

**PLT** — 为 ELF 外部函数调用提供稳定跳板的过程链接表（Ch 7）。

**RVA** — 相对映像基址的虚拟地址，不能直接当文件偏移（Ch 5, 9）。

**SO-NAME** — Linux 共享库对外表达 ABI 主版本的运行时身份（Ch 8）。

**TLS** — 每个线程拥有独立实例的存储机制（Ch 10, 11）。

**入口函数** — 映像开始执行的启动代码，通常先于 main（Ch 6, 11, 13）。

**调用约定** — 参数、返回值、寄存器保存和栈清理由谁负责的规则（Ch 10）。

**动态链接** — 在装载或运行时解析共享对象、符号和地址修正（Ch 7, 9）。

**符号** — 目标文件中供链接器识别定义与引用的名字记录（Ch 3, 4）。

**链接脚本** — 控制链接入口、输出节、地址和布局的描述（Ch 4, 13）。

**目标文件** — 已含机器码和元数据但尚未完成最终链接的结构化产物（Ch 2, 3）。

**强/弱符号** — 影响同名定义选择和冲突处理的绑定规则（Ch 4）。

**系统调用** — 用户态进入内核服务的受控接口（Ch 12）。

**虚拟地址空间** — 进程看到的独立地址视图（Ch 1, 6, 10）。

**页错误** — 地址翻译或权限检查不能直接完成时触发的异常，可用于按需装载（Ch 6）。

**重定位** — 根据最终布局修正机器码或数据中的地址相关字段（Ch 4, 7, 9）。

**Section** — 供链接和分析使用的逻辑内容单元（Ch 3）。

**Segment** — 供装载器映射的执行视图单元（Ch 6）。
