# Cheatsheet

## 现象到证据

| 现象 | 先检查 | 决策规则 |
|---|---|---|
| 宏/声明异常 | 预处理输出 | 若展开已错，停止向链接阶段追查 |
| undefined reference | 符号表、重定位、库顺序 | “库里有字符串”不等于存在可用定义 |
| duplicate symbol | 强弱绑定、COMMON、归档成员 | 显式消除冲突，不依赖偶然选择 |
| 链接成功但跳错 | 重定位类型、ABI、map | 名字解析正确不代表引用修正正确 |
| `main` 前崩溃 | 解释器、依赖、重定位、构造器、CRT | 先在真实入口和构造链取证 |
| 首次外部调用崩溃 | PLT/GOT/IAT、解析器 | 区分首次绑定与后续缓存路径 |
| 找到错误共享库 | 搜索路径、SO-NAME、绝对路径 | 记录实际加载对象，不只记录文件名 |
| 段错误/访问冲突 | 映射、权限、对象生命周期 | 崩溃点可能晚于首次破坏点 |
| 返回后栈坏 | 调用约定、保存寄存器、栈清理 | 调用方与被调方必须使用同一 ABI |
| free 时崩溃 | 分配来源、双重释放、越界写 | 跨 CRT/模块释放先视为高风险 |
| I/O 结果异常 | FILE 缓冲、fd/HANDLE、短读写、文本转换 | 高层调用不等于一次系统调用 |

## 静态还是动态

| 约束 | 倾向静态 | 倾向动态 |
|---|---|---|
| 独立部署、依赖冻结 | ✓ |  |
| 多进程共享代码页 |  | ✓ |
| 单独升级模块 |  | ✓，但必须治理 ABI |
| 运行时插件 |  | ✓ |
| 最小运行时搜索面 | ✓ |  |
| 文件尺寸敏感 |  | 通常 ✓ |

## 二进制坐标规则

- ELF：链接问题先看 section；装载与权限先看 segment。
- PE：始终标注 file offset、RVA、VA；`VA = ImageBase + RVA`，RVA 到文件偏移需经过所在节换算。
- ASLR/PIE 开启时，不用静态地址直接解释运行时地址。

## 共享库版本规则

- 兼容增加：可保持 ABI 主版本，但仍要验证语义。
- 删除符号、改变签名/布局/调用约定：提升 ABI 主版本。
- Linux：真实名负责具体版本，SO-NAME 负责运行时 ABI，链接名服务开发链接。
- 跨 DLL/so：明确谁分配、谁释放、谁拥有句柄、错误如何传递。

## 常用检查意图

| 意图 | 工具类别 |
|---|---|
| 节、段、符号、重定位 | `readelf` / `objdump` / `nm` |
| 链接布局 | linker map、verbose link |
| 动态依赖与绑定 | loader trace、模块列表、IAT/GOT/PLT 检查 |
| 进程映射 | `/proc/<pid>/maps`、调试器 memory map |
| 调用约定 | 反汇编、寄存器与栈快照 |

命令选项和输出字段随平台与版本变化；执行前查看当前工具 `--help`，并用最小样本验证解释。
