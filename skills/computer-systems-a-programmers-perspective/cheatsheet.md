# 决策速查表

## 遇到什么，先做什么

| 现象 | 首步 | 因为 |
|---|---|---|
| 整数结果反常 | 固定位宽、符号性和位模式 | 机器整数按模运算，类型转换会改解释或数值 |
| 浮点比较失败 | 检查表示范围、舍入和运算次序 | 浮点不满足实数的全部代数律 |
| 本地崩溃 | 取故障地址、调用栈和消毒器报告 | 先确定越界、权限或生命周期事实 |
| 性能下降 | 建基线并定位热点 | 未测量无法知道瓶颈或改动收益 |
| 缓存不佳 | 写出访问次序、步长与工作集 | 局部性由地址序列而非数据类型名称决定 |
| 链接错误 | 查符号定义、引用和重定位 | 编译成功不代表符号已解析 |
| 子进程残留 | 查 `wait/waitpid` 与信号时序 | 终止不等于已回收 |
| 页故障/段错误 | 分离映射、驻留、权限 | 三者产生不同处置路径 |
| I/O 少读少写 | 按返回值循环推进 | 字节流不保证一次完成请求 |
| 连接失败 | 分层查 DNS、地址、连接、协议 | 各层错误语义不同 |
| 偶发并发错误 | 列共享状态与允许交错 | 单次成功运行没有证明力 |
| 多线程不加速 | 测串行比例和争用 | 加速受串行段与同步成本限制 |

## 关键分解

```text
源代码 → 预处理 → 编译 → 汇编 → 可重定位对象 → 链接 → 可执行文件 → 装载/运行
虚拟地址 = VPN | VPO → TLB/页表 → PPN | PPO = 物理地址
网络请求 = 名称解析 → 连接 → 字节流 → 消息边界 → 应用语义
资源生命周期 = 创建 → 引用/转移 → 使用 → 关闭/回收
```

## 选择矩阵

| 选择 | 适合 | 代价/约束 |
|---|---|---|
| 条件传送 | 分支难预测且两边计算安全、便宜 | 两路都可能计算，不能隐藏副作用 |
| 循环展开 | 降低控制开销、暴露并行性 | 代码膨胀，尾部需处理 |
| 分块 | 工作集可切进缓存 | 参数依赖机器和数据布局 |
| 静态库 | 构建时纳入目标 | 更新需重新链接，顺序影响解析 |
| 共享库 | 多程序共享、可独立更新 | 装载路径与版本兼容更复杂 |
| `mmap` | 文件映射、共享页、按需加载 | 页粒度、权限和生命周期需明确 |
| Unix I/O | 描述符、套接字、重定向 | 自己处理短计数与错误 |
| 标准 I/O | 格式化与缓冲文件操作 | 避免与底层 I/O 无协调混用 |
| 进程 | 隔离和故障边界优先 | IPC 与切换较重 |
| I/O 多路复用 | 大量非阻塞会话 | 显式状态机复杂 |
| 线程 | 共享内存和任务表达自然 | 竞态、死锁、回收责任 |

## 必查不变量

- 数值：位宽明确；移位合法；截断和扩展符合意图。
- 栈与缓冲区：对象边界、长度、终止符和返回地址不被破坏。
- 缓存：块大小、组映射、访问步长和工作集来自目标机器证据。
- 链接：每个引用有唯一合适定义；重定位类型匹配地址生成方式。
- 进程：每个子进程最终被回收；描述符继承符合最小权限。
- 堆：块对齐、不重叠、边界一致；释放只发生一次。
- I/O：正返回推进；0 是 EOF；`EINTR` 重试；错误路径关闭资源。
- 网络：输入有边界、超时与验证；TCP 不假定消息边界。
- 并发：共享可变对象有同步协议；锁顺序一致；退出路径不遗锁。

## 证据边界

精确汇编、公式、页表字段或常量先回看原 PDF；再以目标编译器、ABI、处理器和操作系统验证。基准只说明给定输入与环境；竞态检测只证明发现的错误，不证明所有交错均正确。
