# 第 9 章：虚拟内存

## Core Idea

虚拟内存同时承担三项工作：把磁盘当作物理内存的后备缓存、为每个进程提供一致的私有地址空间、用页表权限隔离进程与内核。分析地址问题时，不要只问“指针是多少”，而要沿着虚拟地址、页表、物理页、映射对象和权限逐层追踪。

## Frameworks Introduced

### 地址翻译链

1. 将虚拟地址拆成虚拟页号 `VPN` 与页内偏移 `VPO`。
2. 先用 `VPN` 查询 TLB；未命中时遍历多级页表。
3. 页表项若有效，取得物理页号 `PPN`，与不变的页内偏移组合成物理地址。
4. 页表项若无效但映射合法，触发缺页异常，由内核调入页面并重启指令。
5. 映射不存在或权限不符，则进程收到故障信号。

### 动态分配器的设计空间

分配器维护由已分配块和空闲块组成的堆。核心决策是：如何记录块边界、如何查找合适空闲块、如何切分大块，以及何时合并相邻空闲块。评价时同时看吞吐率与峰值内存利用率，不能只优化一项。

## Key Concepts

- **页表**：由操作系统维护、硬件查询的映射与保护元数据；多级结构只为实际使用的地址范围分配下级表。
- **TLB**：页表项的小型高速缓存；命中可避免多级页表访问。
- **按需调页**：页面第一次被访问时才从后备存储载入；工作集超出物理内存会导致颠簸。
- **匿名映射与文件映射**：前者常用于堆或零填充页，后者把文件内容映射进地址空间；私有映射通过写时复制隔离修改。
- **碎片**：内部碎片是块内未被有效载荷使用的空间；外部碎片是总量足够却缺少足够大的连续空闲块。
- **隐式、显式与分离空闲链表**：依次以扫描全部块、只链接空闲块、按大小类别组织空闲块来换取不同的速度与复杂度。
- **边界标记**：在块头/块尾保存尺寸和分配位，使相邻空闲块可在常数时间内合并。
- **垃圾收集**：把堆视为对象图，从根集合标记可达对象，再回收未标记对象；保守收集器可能把非指针位模式误认作指针。

## Mental Models

- 把地址空间看成“稀疏的映射表”，不是一段真实且连续的 RAM。
- 把一次内存访问看成两次缓存问题：先缓存地址翻译，再缓存数据。
- 把 `malloc` 返回的内存看成分配器管理块中的有效载荷，而不是裸字节数组；块周围还有对齐、尺寸和链表元数据。

## Anti-patterns

- 用物理内存大小推断进程能否获得某个虚拟地址范围。
- 把 `malloc` 成功等同于所有页面已经驻留物理内存。
- 忘记 `sizeof`、终止符或乘法溢出，造成越界分配。
- 释放非堆指针、重复释放、释放后继续使用，或失去唯一指针造成泄漏。
- 为性能手写分配器，却没有校验对齐、块重叠、空闲链表一致性和合并不变量。

## Code Examples

下面的模式在计算数组字节数前检查乘法溢出，并保持单一清理路径：

```c
size_t n = /* element count */;
if (n > SIZE_MAX / sizeof(int)) {
    /* reject impossible allocation */
    return -1;
}

int *a = malloc(n * sizeof(*a));
if (a == NULL) return -1;

/* use a within [0, n) */
free(a);
a = NULL;
```

该模式只解决尺寸溢出与局部生命周期问题；共享所有权、并发访问和敏感数据清除仍需单独设计。

## Reference Tables

| 现象 | 翻译路径上的原因 | 首要检查 |
|---|---|---|
| 访问很快 | TLB 命中且数据缓存命中 | 是否可稳定复现 |
| 偶发慢访问 | TLB 或数据缓存未命中 | 工作集、步长、页大小 |
| 缺页后恢复 | 合法页尚未驻留 | 主缺页/次缺页、映射类型 |
| 立即崩溃 | 无映射或权限不符 | 地址、页权限、调用栈 |
| 内存增长 | 活对象、碎片或未归还页 | 分配轨迹与驻留集分别测量 |

| 空闲块策略 | 优势 | 代价 |
|---|---|---|
| 首次适配 | 实现简单、通常较快 | 堆前部易积累小碎片 |
| 下一次适配 | 避免总从堆头扫描 | 利用率不一定改善 |
| 最佳适配 | 减少当次剩余空间 | 搜索贵，可能产生大量微小块 |
| 分离链表 | 兼顾常见尺寸的速度 | 类别、切分和合并逻辑更复杂 |

## Worked Example

假设页大小为 4 KiB，则低 12 位是页内偏移。虚拟地址 `0x12345` 的 `VPN` 为 `0x12`，`VPO` 为 `0x345`。若页表把 `VPN 0x12` 映射到 `PPN 0x8A`，物理地址就是 `0x8A345`；翻译只替换页号，不改变页内偏移。若该页表项为只读而访问是写操作，结果是保护故障，不是调入另一个页面。

## Key Takeaways

- 将映射、驻留和权限视为三个不同问题。
- TLB 优化翻译，多级页表节省页表空间，缓存优化数据访问。
- 动态分配器必须维护对齐、边界、无重叠、空闲结构和合并不变量。
- 排查内存错误时优先使用地址消毒器、Valgrind 类工具和最小复现，不靠肉眼猜指针。
- 复制精确位宽、页表格式或代码前，应结合目标体系结构和原书页面复核。
