# 术语表

按英文术语排序；括号标出主要章节。

- **ABI — Application Binary Interface**：规定调用约定、对象格式、寄存器使用和二进制边界。（Ch 3, 7）
- **Address translation — 地址翻译**：把虚拟页号经 TLB/页表映射为物理页号，页内偏移保持不变。（Ch 9）
- **Amdahl's law — 阿姆达尔定律**：整体加速受不可优化或不可并行部分限制。（Ch 5, 12）
- **Cache — 高速缓存**：以块为单位保存较低层数据的副本，利用时间与空间局部性。（Ch 6）
- **Calling convention — 调用约定**：约定参数、返回值、保存寄存器和栈帧组织。（Ch 3）
- **Condition code — 条件码**：由算术/逻辑操作设置、供条件跳转或条件传送读取的状态位。（Ch 3）
- **Critical path — 关键路径**：决定计算完成时间的最长依赖链。（Ch 4, 5）
- **Deadlock — 死锁**：多个执行流循环等待彼此持有的资源，无法继续。（Ch 12）
- **Descriptor — 文件描述符**：进程描述符表中的小整数索引，引用内核打开对象。（Ch 10）
- **ELF — Executable and Linkable Format**：Linux 常见的可重定位、可执行与共享对象格式。（Ch 7）
- **Endianness — 字节序**：多字节对象在内存中从低地址到高地址的字节排列。（Ch 2）
- **Exception — 异常**：控制从当前程序转移到内核处理程序的事件。（Ch 8）
- **False sharing — 伪共享**：线程修改同一缓存块中的不同数据而引发一致性流量。（Ch 6, 12）
- **Fragmentation — 碎片**：分配空间因块内浪费或外部不连续而难以有效利用。（Ch 9）
- **Hazard — 流水线冒险**：数据依赖或控制变化妨碍流水线按理想节拍推进。（Ch 4）
- **Heap — 堆**：动态分配器管理的虚拟地址区域，由已分配块和空闲块组成。（Ch 9）
- **Instruction set architecture — 指令集体系结构**：软件可见的指令、寄存器、内存和异常接口。（Ch 1, 4）
- **Linker — 链接器**：解析符号并重定位节与引用，生成可执行或共享对象。（Ch 7）
- **Locality — 局部性**：程序倾向近期再次访问对象或访问相邻对象的性质。（Ch 6）
- **Memory mapping — 内存映射**：将文件或匿名对象关联到一段虚拟地址区域。（Ch 9）
- **Page fault — 缺页异常**：页表无法直接完成合法访问时转入内核处理的异常。（Ch 9）
- **Pipeline — 流水线**：让多条指令的不同阶段重叠执行以提高吞吐。（Ch 4）
- **Process — 进程**：正在执行程序的抽象，拥有私有虚拟地址空间与逻辑控制流。（Ch 8）
- **Race condition — 竞态条件**：结果依赖执行流之间不可控的时序或交错。（Ch 12）
- **Relocation — 重定位**：把符号引用修补为最终地址或运行时可解析位置。（Ch 7）
- **Semaphore — 信号量**：通过原子 P/V 操作表示资源数量或提供互斥。（Ch 12）
- **Signal — 信号**：内核或进程通知目标进程某类事件的软件机制。（Ch 8）
- **Socket — 套接字**：网络通信端点在文件描述符接口中的表示。（Ch 11）
- **Spatial locality — 空间局部性**：访问某对象后很可能访问邻近地址。（Ch 6）
- **Temporal locality — 时间局部性**：访问某对象后很可能在近期再次访问。（Ch 6）
- **Thread — 线程**：进程内独立调度的逻辑流，共享地址空间与多数进程资源。（Ch 12）
- **TLB — Translation Lookaside Buffer**：缓存最近页表项的地址翻译缓存。（Ch 9）
- **Two's complement — 补码**：现代机器表示有符号整数的模数编码。（Ch 2）
- **Virtual memory — 虚拟内存**：以地址翻译实现缓存、地址空间管理和保护的机制。（Ch 9）
- **Working set — 工作集**：一段时间内程序活跃使用的数据或页面集合。（Ch 6, 9）
